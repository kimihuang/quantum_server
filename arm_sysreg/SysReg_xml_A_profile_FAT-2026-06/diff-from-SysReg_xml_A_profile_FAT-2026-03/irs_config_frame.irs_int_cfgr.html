IRS_INT_CFGR, IRS Interrupt Configuration Register

The IRS_INT_CFGR characteristics are:

Purpose

Returns the configuration of the interrupt selected in IRS_INT_SELR.

Configuration

This register is present only when FEAT_GICv5_EXT is implemented and FEAT_GICv5_EXT is implemented. Otherwise, direct accesses to IRS_INT_CFGR are RES0.

This register reports the configuration and state for the interrupt selected by IRS_INT_SELR.

This register is updated after a write that sets IRS_INT_SELR.S to 1 when IRS_INT_STATUSR.{V, IDLE} is {1, 1}.

If there is an update to the interrupt configuration and state following the write that sets IRS_INT_SELR.S to 1, it is IMPLEMENTATION DEFINED whether the old or the new configuration and state is reported in this register.

Attributes

IRS_INT_CFGR is a 64-bit register.

This register is part of the IRS_CONFIG_FRAME block.

Accessing IRS_INT_CFGR

Accesses to this register use the following encodings:

Accessible at offset 0x03E8 from IRS_CONFIG_FRAME

  • When IRS_IDR0.INTCFG != '1', accesses to this register are RAZ/WI.
  • When IRS_INT_STATUSR.[V,IDLE] != '11', accesses to this register are UNKNOWN/WI.
  • Otherwise, accesses to this register are RO.
