IRS_INT_SELR, IRS Interrupt Selection Register

The IRS_INT_SELR characteristics are:

Purpose

Selects an interrupt whose configuration can be queried and updated using other registers.

Configuration

This register is present only when FEAT_GICv5_EXT is implemented and FEAT_GICv5_EXT is implemented. Otherwise, direct accesses to IRS_INT_SELR are RES0.

The effects of a write to this register are not guaranteed to have completed before IRS_INT_STATUSR.IDLE is 1.

Attributes

IRS_INT_SELR is a 64-bit register.

This register is part of the IRS_CONFIG_FRAME block.

S, bit [63]

Writing 1 to this field selects an interrupt. The configuration and state of the selected interrupt can be read using IRS_INT_CFGR and updated using the following registers:

  • IRS_INT_CACTIVER
  • IRS_INT_ENABLER
  • IRS_INT_HMR
  • IRS_INT_IAFFIDR
  • IRS_INT_PENDINGR
  • IRS_INT_PRIORITYR
SMeaning
0b0

The write to this register has no effect.

0b1

The write to this register selects an interrupt.

If this field is not set to 1 on a write to this register, updates to any other field in this register has no effect beyond updating the value of that field.

This means that if IRS_INT_STATUSR.V is updated as a result of a write to another register, IRS_INT_STATUSR.V reflects whether the interrupt selected when this field was set to 1 is valid.

Access to this field is WO/UNKNOWN.

VIRT, bit [62]
When IRS_IDR0.VIRT == '1':

Whether this register selects a virtual or physical interrupt.

VIRTMeaning
0b0

This register selects a physical interrupt.

0b1

This register selects a virtual interrupt for the VM specified by VM_ID.

The reset behavior of this field is:

  • On a Warm reset, this field resets to an architecturally UNKNOWN value.


Otherwise:

Reserved, RES0.

Reserved, RES0.

VM_ID, bits [47:32]

When VIRT is 1, identifies the VM of the selected virtual interrupt.

Otherwise, this field is RES0

Bits [28:24]

Reserved, RES0.

ID, bits [23:0]

The INTI.ID of the selected interrupt.

Any interrupt reachable from the IRS can be selected.

The reset behavior of this field is:

  • On a GIC reset, this field resets to an UNKNOWN value.

Accessing IRS_INT_SELR

Accesses to this register use the following encodings:

Accessible at offset 0x03D8 from IRS_CONFIG_FRAME

  • When IRS_IDR0.INTCFG != '1', accesses to this register are RAZ/WI.
  • When IRS_INT_STATUSR.IDLE == '0', accesses to this register are RO.
  • Otherwise, accesses to this register are UNKNOWN/WI.
