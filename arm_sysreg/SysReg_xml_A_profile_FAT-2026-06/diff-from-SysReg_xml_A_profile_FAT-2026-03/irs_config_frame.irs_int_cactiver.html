IRS_INT_CACTIVER, IRS Interrupt Clear Active state Register

The IRS_INT_CACTIVER characteristics are:

Purpose

Deactivates the interrupt selected in IRS_INT_SELR.

Configuration

This register is present only when FEAT_GICv5_EXT is implemented and FEAT_GICv5_EXT is implemented. Otherwise, direct accesses to IRS_INT_CACTIVER are RES0.

The effects of a write to this register are not guaranteed to have completed before IRS_INT_STATUSR.IDLE is 1.

Following a write to this register, IRS_INT_STATUSR.V is updated.

Attributes

IRS_INT_CACTIVER is a 32-bit register.

This register is part of the IRS_CONFIG_FRAME block.

Field descriptions

Bits [31:1]

Reserved, RES0.

Deactivate, bit [0]

Clears the interrupt Active state.

DeactivateMeaning
0b0

No update to the interrupt Active state

0b1

Set the interrupt to Inactive

Access to this field is W1C.

Accessing IRS_INT_CACTIVER

Accesses to this register use the following encodings:

Accessible at offset 0x03F8 from IRS_CONFIG_FRAME

  • When IRS_IDR0.INTCFG != '1', accesses to this register are RAZ/WI.
  • When IRS_INT_STATUSR.[V,IDLE] != '11', accesses to this register are UNKNOWN/WI.
  • Otherwise, accesses to this register are WO.
