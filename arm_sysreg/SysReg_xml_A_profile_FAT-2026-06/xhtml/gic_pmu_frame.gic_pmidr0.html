GIC_PMIDR0, GIC PMU Identification Register 0

The GIC_PMIDR0 characteristics are:

Purpose

GIC PMU Identification Register 0. Contains read-only fields with information about the GIC PMU.

Configuration

This register is present only when FEAT_GICv5_EXT is implemented. Otherwise, direct accesses to GIC_PMIDR0 are RES0.

Attributes

GIC_PMIDR0 is a 32-bit register.

This register is part of the GIC_PMU_FRAME block.

Bits [31:7]

Reserved, RES0.

DOM_RL, bit [6]

Whether a component in the agent being monitored supports the Realm Interrupt Domain.

The value of this field is an IMPLEMENTATION DEFINED choice of:

DOM_RLMeaning
0b0

The Realm Interrupt Domain is not supported by any component in the agent being monitored.

0b1

The Realm Interrupt Domain is supported by a component in the agent being monitored.

Access to this field is RO.

DOM_EL3, bit [5]

Whether a component in the agent being monitored supports the EL3 Interrupt Domain.

The value of this field is an IMPLEMENTATION DEFINED choice of:

DOM_EL3Meaning
0b0

The EL3 Interrupt Domain is not supported by any component in the agent being monitored.

0b1

The EL3 Interrupt Domain is supported by a component in the agent being monitored.

Access to this field is RO.

DOM_NS, bit [4]

Whether a component in the agent being monitored supports the Non-secure Interrupt Domain.

The value of this field is an IMPLEMENTATION DEFINED choice of:

DOM_NSMeaning
0b0

The Non-secure Interrupt Domain is not supported by any component in the agent being monitored.

0b1

The Non-secure Interrupt Domain is supported by a component in the agent being monitored.

Access to this field is RO.

DOM_S, bit [3]

Whether a component in the agent being monitored supports the Secure Interrupt Domain.

The value of this field is an IMPLEMENTATION DEFINED choice of:

DOM_SMeaning
0b0

The Secure Interrupt Domain is not supported by any component in the agent being monitored.

0b1

The Secure Interrupt Domain is supported by a component in the agent being monitored.

Access to this field is RO.

OACE, bit [2]

Whether the PMU implements the observability and access control extension.

The value of this field is an IMPLEMENTATION DEFINED choice of:

OACEMeaning
0b0

The PMU does not implement the observability and access control extension.

0b1

The PMU implements the observability and access control extension.

Access to this field is RO.

ITS_PMU, bit [1]

Whether this PMU counts events from an ITS.

This field can be interpreted in combination with IRS_PMU to determine the GIC PMU configuration.

See 'GIC Performance Monitoring Unit (PMU)' in Arm® Generic Interrupt Controller Architecture Specification, GIC architecture version 5 (ARM IHI 111701) for more information.

The value of this field is an IMPLEMENTATION DEFINED choice of:

ITS_PMUMeaning
0b0

This PMU does not count events from an ITS.

0b1

This PMU counts events from at least one ITS.

Access to this field is RO.

IRS_PMU, bit [0]

Whether this PMU counts events from an IRS.

This field can be interpreted in combination with ITS_PMU to determine the GIC PMU configuration.

See 'GIC Performance Monitoring Unit (PMU)' in Arm® Generic Interrupt Controller Architecture Specification, GIC architecture version 5 (ARM IHI 111701) for more information.

The value of this field is an IMPLEMENTATION DEFINED choice of:

IRS_PMUMeaning
0b0

This PMU does not count events from an IRS.

0b1

This PMU counts events from an IRS.

Access to this field is RO.

Accessing GIC_PMIDR0

Accesses to this register use the following encodings:

Accessible at offset 0xD80 from GIC_PMU_FRAME

  • When PMROOTCR.RA is implemented, an access is Secure, and PMROOTCR.RA IN {'001', '000'}, accesses to this register are RAZ/WI.
  • When PMROOTCR.RA is implemented, an access is Realm, and PMROOTCR.RA IN {'010', '000'}, accesses to this register are RAZ/WI.
  • When PMROOTCR.RA is implemented, an access is Non-secure, and PMROOTCR.RA != '011', accesses to this register are RAZ/WI.
  • When PMSCR.NSRA is implemented, (an access is Non-secure or an access is Realm), and PMSCR.NSRA == '0', accesses to this register are RAZ/WI.
  • Otherwise, accesses to this register are RW.
