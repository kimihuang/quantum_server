IRS_INT_STATUSR, IRS Interrupt Status Register

The IRS_INT_STATUSR characteristics are:

Purpose

IRS Interrupt Status Register

Reports whether a write that sets IRS_INT_SELR.S to 1 is complete and selects a valid interrupt.

Also reports whether the effects of a write to any IRS interrupt configuration register is complete.

Configuration

This register is present only when FEAT_GICv5_EXT is implemented and FEAT_GICv5_EXT is implemented. Otherwise, direct accesses to IRS_INT_STATUSR are RES0.

Attributes

IRS_INT_STATUSR is a 32-bit register.

This register is part of the IRS_CONFIG_FRAME block.

Field descriptions

RES0VIDLE

Bits [31:2]

Reserved, RES0.

V, bit [1]

Whether the value last written to IRS_INT_SELR selects a valid interrupt.

This field is updated if and only if any of the following occur:

  • A write that sets IRS_INT_SELR.S to 1.
  • A write to any of the following registers:
    • IRS_INT_CACTIVER.
    • IRS_INT_ENABLER.
    • IRS_INT_HMR.
    • IRS_INT_IAFFIDR.
    • IRS_INT_PENDINGR.
    • IRS_INT_PRIORITYR.

When IDLE is 0, the value of this field is UNKNOWN.

VMeaning
0b0

The interrupt selected using IRS_INT_SELR is not valid.

0b1

The interrupt selected using IRS_INT_SELR is valid.

This field resets to 0 to indicate that there was no write to IRS_INT_SELR that selected a valid interrupt on this IRS since the IRS was reset.

The reset behavior of this field is:

  • On a GIC reset, this field resets to '0'.

IDLE, bit [0]

A write that sets IRS_INT_SELR.S to 1 is complete when this field is 1.

When this field is 1 and V is 1, a read from IRS_INT_CFGR returns values for the selected interrupt.

Following a write to one of the following registers, when this field returns 1, the effects of the write have completed:

  • IRS_INT_CACTIVER.
  • IRS_INT_ENABLER.
  • IRS_INT_HMR.
  • IRS_INT_IAFFIDR.
  • IRS_INT_PENDINGR.
  • IRS_INT_PRIORITYR.
IDLEMeaning
0b0

The effects of the last write that set IRS_INT_SELR.S to 1 or any write to an interrupt configuration register is not guaranteed to be complete.

0b1

The effects of the last write that set IRS_INT_SELR.S to 1 and any writes to interrupt configuration registers are complete.

This field resets to 1 to allow initial writes to registers Guarded by this field. Because there has been no write at reset, a reset value of 1 does not imply that any write to IRS_INT_SELR to select an interrupt is complete.

The reset behavior of this field is:

  • On a GIC reset, this field resets to '1'.

Accessing IRS_INT_STATUSR

Accesses to this register use the following encodings:

Accessible at offset 0x03E0 from IRS_CONFIG_FRAME

  • When IRS_IDR0.INTCFG != '1', accesses to this register are RAZ/WI.
  • Otherwise, accesses to this register are RO.
